# Style — manifest & doc conventions

See [AGENTS.md](../../AGENTS.md) for the canonical rules. Highlights:

- Edit `.claude-plugin/marketplace.json` (the Claude manifest) only; the Codex
  and Cursor manifests are generated by `make generate`.
- Plugin entries use `"source": { "source": "github", "repo": "...", "ref": "main" }`.
  Never change the source type.
- Keep plugin descriptions to one line; they are informational only.
- Every new plugin needs: a manifest entry, a README table row, and a
  `CHANGELOG.md` entry under `[Unreleased]`.
